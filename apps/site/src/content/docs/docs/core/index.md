Core functionality for tracking changes to MobX observables and validating them.

This package provides three core primitives for reactive state management:

- [Watcher](/docs/core/watcher/): Fine-grained change tracking for MobX observables
- [Validator](/docs/core/validator/): Declarative synchronous and asynchronous validation
- [Nested](/docs/core/nested/): Hierarchical tracking of nested object structures
