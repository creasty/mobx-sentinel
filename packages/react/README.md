Utility hooks and standard bindings for React applications using `@mobx-sentinel/form`.

Documentation: [guide](https://mobx-sentinel.creasty.com/docs/react/) · [API reference](https://mobx-sentinel.creasty.com/apis/react/)

<pre><code>npm install --save <b>@mobx-sentinel/react</b></code></pre>

- React hooks that automatically handle component lifecycle under the hood.
- Standard bindings for most common form elements.
